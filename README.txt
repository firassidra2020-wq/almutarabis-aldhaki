المتربص الذكي — دليل التعريض الضوئي
نسخة توزيع PWA
المؤلف: توير نصرالدين

المحتوى:
- تدريب وفق APC 2.0
- 12 وضعية مهنية للتعريض الضوئي
- أسئلة قبل الحل
- اقتراح ISO والفتحة والغالق وتوازن الأبيض
- حل مرجعي وتعليل وتغذية راجعة
- نشاط إدماجي وتقييم كفاءة
- محاكاة مثلث التعريض
- كاميرا الهاتف بعد مرحلة المحاولة
- تحليل تقريبي لسطوع المشهد
- حفظ النتائج محليًا
- تصدير النتائج CSV ونسخة احتياطية JSON
- دعم الهاتف والكمبيوتر
- قابل للتثبيت كتطبيق PWA

التوزيع:
1. ارفع محتويات المجلد إلى استضافة HTTPS تدعم الملفات الثابتة.
2. تأكد أن index.html في الصفحة الرئيسية.
3. افتح الرابط من الهاتف.
4. استخدم «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
5. أنشئ QR Code من الرابط العام للتطبيق.

ملاحظة مهمة:
الكاميرا تعمل في المتصفحات الحديثة عند استخدام HTTPS أو localhost وبعد منح إذن الكاميرا.
التحليل الضوئي داخل التطبيق تعليمي وتقريبي ولا يتحكم فعليًا في ISO أو فتحة أو سرعة غالق كاميرا الهاتف.

النتائج الحالية تحفظ على جهاز المتربص. للتجميع المركزي بين عدة أجهزة نحتاج في مرحلة لاحقة قاعدة بيانات وحسابات/رموز للمتربصين.
